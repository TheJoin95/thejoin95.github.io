# Maintain the portfolio

Current handoff: 2026-11-14. The application and blog are implemented, and a
reviewed Netlify draft exists. Production cutover (MIC-30) and live-release
verification (MIC-31) are still Backlog; this guide does not claim they happened.

| What you want to do | Start here |
| --- | --- |

| Add/edit a project, case study, photo or fox asset | [Project and asset updates](projects.md) |

| Record a real production release | [Release record template](release-record.md) |

Use Bun, the version pinned in `.bun-version`, and the frozen lockfile. The
application uses Next.js App Router, TypeScript, Tailwind and Radix/shadcn.
Repository Markdown is the blog editor; no database, CMS account or external API
is needed to read or publish writing. The newsletter endpoint requires a server;
GitHub Pages/static export cannot replace the current deployment unchanged.

## Where changes belong

| Content | Authoritative location |
| --- | --- |
| New articles/sketchbooks | `content/journal/<slug>.md` |
| Approved new writing images | `public/media/journal/` |
| Legacy article sources/downloads | Existing migrated Markdown and `public/articles/`; preserve original bytes |
| Build-generated article route inventory | `src/content/journal-routes.json`, regenerated by `build:journal` |
| Full project index/Play directory | `src/content/work.ts`; Play derives from it |
| Featured project records and media | `src/content/selected-projects.ts`, `src/content/featured-media.ts` |
| Case studies and publication gate | `src/content/case-studies.ts` |
| Home identity/featured writing | `src/content/home.ts` |
| About/talks and contact destinations | `src/content/about.ts`, `src/lib/site.ts`, About page/components |
| Shared metadata/discovery | `src/lib/seo.ts`, `src/lib/discovery.ts`, existing share-image routes |
| Fox source and provenance | `assets/fox/model.ts`, `assets/fox/README.md`, `assets/fox/manifest.json` |
| Design rules | `DESIGN.md`, `docs/design/responsive-layouts.md` |

Blog date, draft and filename changes require regeneration/rebuild/restart.
Published URLs are contracts. Keep real attribution, media rights and status
visible. Never put credentials in Markdown, public files, issues or commits.
`draft: true` hides publication; it is not private storage for public assets.
