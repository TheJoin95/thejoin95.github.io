# Side-project case study sources

The project stories distinguish individual contributions from shared product
capabilities. The larger GitHub index links to repositories and pull request
history for projects whose contributions are documented in GitHub.

- Certo uses the public repository and merged Nuxt 4 and pnpm migration, pull
  request 115.
- Vitni and Vitni Credentials are separate projects. The repair story uses the
  checkout's guide search, repair steps, localization, and retailer-link
  changes. The credentials story uses the checkout's role mapping, API
  packaging, and setup documentation changes. These stories use public-facing
  summaries of the project work.
- Ambisonic Audio uses the public Python repository and the preserved 2018
  Journal article from `origin/old`.
- Open Source Day and Browsir cite merged GitHub pull requests by TheJoin95.
- Open Source Wrapped and YouTube to Anchor.fm cite their public source and
  the relevant commits from project history.

The GitHub index uses public non-fork repositories on TheJoin95's profile and
public merged pull requests authored by TheJoin95. The latter were checked in
four date buckets through 2026-11-18. The link to GitHub search includes public
pull requests of all statuses.
